JMSFusion 4.0.0.11 for Jellyfin 12 (ParticularFlix fork). Mobile layout, a security fix and the trailer improvements of the unpublished 4.0.0.10. Same plugin GUID, settings are kept.

## 📦 Install

- Catalog URL: `https://raw.githubusercontent.com/hebolysouza/ParticularFlix-JMSFusion/main/manifest.json`
- Or manual: put the three files of `JMSFusion-4.0.0.11-server.zip` (DLL, `meta.json`, `icon.png`) in the plugin folder and restart Jellyfin.
- Requires Jellyfin 12.x (targetAbi 12.0.0.0, net10.0). Validated on 12.3. Jellyfin 10.11.x: stay on 3.8.2.45.

## ⬆️ Upgrade notes

- **Update soon**: this release closes a security hole present in every earlier fork build (see Security).
- The mobile header lives in `extras/particularflix-modern-header.js`. On Jellyfin 12 it runs from the JMS `custom` folder (`<config>/data/plugins/configurations/JMSFusion/custom/`), not from the DLL: copy the new file there to get the phone header.
- Nothing to change in the settings. Global layout snapshots keep working; the phone slider layout ignores the manual block positions only on phones.

## 🔒 Security

- **Plugin endpoints trusted a forgeable user header.** The Arr, Seerr, Studio Hubs, Trailers, Cast, music sync, parental PIN/access profiles, cinema pre-roll, lyrics, comments and watchlist endpoints took the caller's identity from the `X-Emby-UserId` header (some also from `?userId=`), which any client can write, and they did not require a sign-in. Anyone who knew the administrator's ID could act as the administrator: read the Radarr/Sonarr settings, add movies and series, change access profiles, read another user's watchlist or comment in their name. The identity now comes only from the token validated by Jellyfin.
- **`/Users` no longer lists every account to regular users.** Jellyfin 12 returns all users (names and IDs) to any signed-in user, even users hidden from the login screens. For users who are not administrators the answer is trimmed to their own account.

## ✨ New

- **Phones get their own slider layout**: badges, ratings and audio at the top; logo, tagline, plot with the resume progress bar, director, buttons and genres at the bottom, each block taking only its own height (no overlaps, nothing cut). The card takes almost the whole screen width, buttons are at least 44 px, neighbor cards show only their image and logo, and a thin bar shows the position in the slider.
- **No slide trailer on phones** (portrait or landscape): only the backdrop and the logo, saving data and battery. Tablets and desktop keep the trailer.
- **Mobile header** (brand script): menu, animated logo icon, search, bell, profile avatar and a More menu with SyncPlay, Cast, Jellyfin Enhanced and the JMS settings.
- **Home rows on phones** (native and Home Screen Sections): sized per orientation so a piece of the next card always shows; row arrows hidden on touch screens.
- **JMS settings (F2) for regular users** show only their own options (appearance, layout, slider, studios, positions, pause screen, previews, details, watchlist, notifications, avatar). Server and module settings are admin only.

## 🛠️ Fixes

- New titles get their trailer in seconds instead of minutes (library folder watcher plus a 10 s check).
- Replaced trailers never drop below 720p; trailer downloads pause when the library disk is short on space.
- Portuguese (Brazil) labels fixed ("56 min restantes" and others).

## ⚠️ Known limitations

- The mobile header and slider layout apply to web and web-wrapper clients only (native TV apps do not run the plugin scripts).
- The C# changes of this release were built and validated on the owner's test and production servers; there is no automated test suite.
