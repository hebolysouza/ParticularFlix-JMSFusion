JMSFusion 4.0.0.13 for Jellyfin 12 (ParticularFlix fork). Security release: several plugin routes answered without sign-in, and the configuration sent to regular users carried other users' data. Also: return one user's layout to the default, removed titles leave the slider, and the library toolbar is back on phones. Same plugin GUID, settings are kept.

## 📦 Install

- Catalog URL: `https://raw.githubusercontent.com/hebolysouza/ParticularFlix-JMSFusion/main/manifest.json`
- Or manual: put the three files of `JMSFusion-4.0.0.13-server.zip` (DLL, `meta.json`, `icon.png`) in the plugin folder and restart Jellyfin.
- Requires Jellyfin 12.x (targetAbi 12.0.0.0, net10.0). Validated on 12.3. Jellyfin 10.11.x: stay on 3.8.2.45.

## ⬆️ Upgrade notes

- **Update if your server is reachable from the internet.** Before this release anyone who could reach the server could read, overwrite or delete the list caches (slider, home rows, recommendations) of any user without signing in.
- **Reload every open tab after updating.** Pages still running the previous version do not send the session token on the list cache calls and get 401 until reloaded (the slider then rebuilds once).
- The header change lives in `extras/particularflix-modern-header.js`. On Jellyfin 12 it runs from the JMS `custom` folder (`<config>/data/plugins/configurations/JMSFusion/custom/`), not from the DLL: copy the new file there.

## 🔒 Security

- **List caches required no sign-in**: `/Plugins/JMSFusion/ScopedCache` now requires a signed-in user, and a regular user can only reach their own scope. Administrators and API keys keep full access (cache backup page). Writes are capped at 16 MB.
- **Cinema pre-roll cache required no sign-in**, and `force=true` made the server rebuild the trailer list from the internet on every call. It now requires sign-in; `force` only works for administrators.
- **Configuration sent to regular users** no longer includes other users' watchlists, shares, history, comments, Seerr requests, parental PIN rules or internal service addresses (Jellyfin, Seerr, Sonarr, Radarr URLs and root folders, script folder). API keys were already hidden.
- **Status and Snippet** showed server paths without sign-in; administrators only now. The plugin page sends the session token on all of its calls.
- **Comment author name** came from a request header; it now comes from the signed-in user.

## ✨ New

- **Return one user's layout to the default**: "JMS layout of a user" card on the plugin page (JMSFusion tab). Lists users with their own saved layout and deletes the chosen user's own layout after a confirmation; only that user changes. Recorded in the audit trail. API: `POST /Plugins/JMSFusion/UserSettings/ResetUser`.
- **Removed titles leave the slider and rows**: removing a movie, series or collection discards the list caches of every user once, two minutes after the last removal. Can be turned off with `InvalidateListCachesOnItemRemoval` in the plugin XML.

## 🛠️ Fixes

- **Library toolbar back on phones**: on library pages the header script treated the sort/filter/view toolbar as the navigation pills, hiding it on phones and restyling it on desktop. It now only touches the main toolbar.

## ⚠️ Known limitations

- After removing titles, each user rebuilds the slider once on the next page load.
- The C# changes of this release were built and validated on the owner's test and production servers; there is no automated test suite.
